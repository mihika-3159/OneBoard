# Batch G inference operations

For distributed dispatch, provision a private PostgreSQL database dedicated to the inference queue. Give only the API and inference workers access. Set INFERENCE_QUEUE_URL to its SQLAlchemy PostgreSQL URL in both services. Apply the application's normal database settings to the worker for tenant token accounting. Use verified TLS between hosts. Start one or more workers with `python -m scripts.inference_worker` before routing traffic to the API. Workers initialize the queue schema under a database lock. With no queue URL the gateway uses its synchronous local deployment mode.

The queue holds tenant prompts, partial output, and replies while the request is active. Fetch and deletion use both tenant and request ID. The worker clears the payload at completion. The caller removes the entry on exit and the worker removes expired entries. Disk and backup retention are deployment responsibilities. Two slots are shared across workers. A claim chooses the least recently served waiting tenant, then that tenant's oldest request. Claims are fenced by owner and lease. One expired claim can be recovered before the deadline if no partial output was published. Streamed work with published output expires on interruption to avoid replaying a different continuation. An abandoned caller cannot resume a request after its deadline.

Production workers sample their available host and cgroup memory and host load before generation. Set INFERENCE_MIN_FREE_MIB and INFERENCE_MAX_LOAD_PER_CPU to fit the inference host. With a remote provider these measurements describe the OneBoard worker. Dedicated local Ollama replicas can be configured with OLLAMA_LOCAL_REPLICA_PORT. Retries and failover share the request deadline. Each outbound attempt incurs a tenant token reservation. Only validated embeddings with a configured model digest qualify for the bounded per-process tenant cache, with a 60-second lifetime.

The founder command stream emits newline-delimited JSON. Text fragments are provisional. A final result carries model identity, simulation status and the output-limit flag. Closing the stream cancels local work and removes the durable queue request. A running worker polls ownership every half second and closes the provider connection on cancellation. Structured council, workflow and agent decisions consume completed, validated objects.

The dispatcher waits for an in-flight queue insertion before deleting a cancelled request. Workers flush the final buffered text before committing the terminal reply; a completed stream therefore delivers every fragment even when generation finishes inside the publish interval.

Remote approved Ollama hosts must expose `/oneboard/capacity` on the same approved HTTPS origin, reverse-proxied to the loopback-only `python -m scripts.inference_capacity_server` running on the inference host. Missing or malformed metrics reject admission; set INFERENCE_REMOTE_ACCELERATOR_MIN_MIB for GPU memory checks. Local OpenAI-compatible chat failover is explicitly enabled with INFERENCE_COMPATIBLE_LOCAL_PORT and INFERENCE_COMPATIBLE_DIGESTS, and requires an operator-verified `/oneboard/models` artifact inventory on that local endpoint. It never receives embedding requests. No alternate remote hosts are authorized automatically. Text cache is opt-in, deterministic, short-lived, tenant-bound, model-pinned, and excludes streams, structured decisions, fallback or truncated responses and multi-provider configurations.

All interactive model operations (founder commands, council deliberations, agent generation/testing, workflow generation/teaching, model benchmark and memory search/index) have cancellation and terminal-result contracts. Structured operations use an opt-in NDJSON Accept header and progress heartbeats rather than exposing partial JSON or accepting incomplete decisions; existing JSON clients retain the request-disconnect guard. Browser operations cancel on unmount or explicit Cancel inference. Sandboxed text-only agent tests can explicitly opt into deterministic caching. No other operation enables it.

Batch acceptance rule: complete every numbered requirement in the designated batch, commit implementation and regression tests, verify mandatory checks against the exact head, and stop before the next batch. Do not represent partial implementation or pending checks as closed. Live production infrastructure and external authorizations remain independent gates.

The compatible-provider sidecar serves a verified artifact inventory from INFERENCE_MODEL_ARTIFACTS, a JSON map of model aliases to {path,digest}. Run the sidecar on loopback, launch the compatible server using the exact immutable GGUF path and matching alias, and reverse-proxy `/oneboard/models` to the sidecar and `/v1/` to the model server at the configured compatible port. An artifact whose digest changes is no longer advertised. Use the same approved HTTPS origin for remote capacity telemetry, restrict it to the trusted inference network, and ensure the sidecar sees the provider host/container resource limits. GPU checks currently use NVIDIA telemetry and fail closed if configured but unavailable. Failover reserves time for subsequent providers and never replays a stream after provisional output has been emitted. The health endpoint reports the configured providers rather than only the primary when multiple are enabled.
