# Batch H: Executive council and custom agents

Requirements 29–39. Council citations are exact text matches against a bounded tenant-owned record inventory. They do not verify a real-world claim. Structured synthesis is extractive, with stable adviser argument IDs and record snapshots; free-form model recommendations cannot authorize actions. Conflicts lead to review and interrupted/partial meetings cannot be approved. Persisted stage checkpoints and a founder-controlled reconciliation endpoint recover abandoned meetings.

The agent runtime is read-only by design. A founder defines one to twelve ordered steps, with a root agent and nonrecursive handoffs. Only the bounded read_crm, calculate_metrics, read_memory, and analyze tools exist. Memory documents require explicit IDs in the agent configuration. No provider text can grant tools or delegate. Handoff data is filtered against the receiving agent's grants. Run IDs and idempotency keys are tenant-scoped; a 75-second fenced lease, two claim attempts, 55-second step deadline and 15-minute run deadline bound recovery. A founder advances one checkpoint per request and can cancel; a crash can be resumed after lease expiry. There is no external side-effect runtime. Legacy sandbox behavior remains separate. An agent change invalidates a pinned plan.

Calibration uses prospective, founder-recorded intervals linked to an actual participating adviser, paired with the first recorded observation at or after its due date. Report sample count, per-metric MAE, coverage, 95% Wilson interval, Brier score and recorded task completion. Never describe these as independently verified. The latest 500 decisions and 2000 tasks are bounded; small samples are flagged.

The paired evaluator runs real model inference on fixed synthetic cases with a common rubric. Report both success and failure, including latency, calls and paired scores. A small synthetic evaluation is not evidence of real-world superiority. No production credentials or external data are required.

Forecasts retain provenance separately for founder-recorded estimates and exact model-generated, evidence-linked adviser proposals explicitly registered after approval. Outcomes are not eligible before the due date, and prospective duplicate observations are rejected. Approval revalidates citation snapshots. Read endpoints show effective expired/recoverable status without updating state; a founder advances or cancels a persisted run. Browser creation exposes explicit read-tool grants, document scope and step budget.

Ledger records (invoice, expense, product and non-PII customer fields) are included in the bounded evidence inventory and revalidated by tenant and record ID. A founder can run all remaining approved steps in one cancellable request. The executor stops at an active lease, terminal result, or bounded plan length. Cancel fences the persisted result; an in-flight provider request remains subject to its timeout and disconnect cancellation. The PostgreSQL acceptance suite tests concurrent idempotent planning and exclusive lease acquisition; the unit suite verifies interruption and stale/cross-tenant citations.
